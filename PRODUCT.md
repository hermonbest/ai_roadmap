# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

static HTML/CSS/Vanilla JS

## Users
Absolute beginners with zero prior coding knowledge. They want to go from zero to building and deploying full-stack applications by leveraging AI coding tools.

## Product Purpose
To provide an interactive, self-paced web course that guides users through stages of web development (from HTML basics to deployment) using AI as a primary coding partner.

## Positioning
Focuses primarily on hands-on "Vibe Coding" techniques using AI tools to build apps rapidly, teaching users how to guide AI and think like developers rather than memorizing syntax.

## Operating Context
A client-side web application running entirely in the browser. Progress tracking, bookmarks, and quiz scores are stored locally in the browser's localStorage.

## Capabilities and Constraints
- **Roadmap Stages**: 7 stages of learning content.
- **AI Tutor Widget**: Client-side chat interface for immediate support.
- **Gamification**: XP tracking, progress rings, and lesson completion status.
- **Bookmarks & Reset**: Ability to bookmark lessons and clear browser progress.
- **Command Palette**: Search modal (Ctrl + K) for rapid topic discovery.
- **No Backend**: Operates fully on the client-side with static HTML/CSS/JS.

## Brand Commitments
- **Name**: AI-Powered Coding Roadmap
- **Theme**: Neural Slate & Cyber Violet Design System
- **Fonts**: Space Grotesk (display), Inter (body), JetBrains Mono (code)

## Product Principles
1. **AI-First & Vibe Coding**: Emphasize developer mental models, prompt crafting, and AI pair-programming over manual syntax compilation.
2. **Interactive & Frictionless**: Run all coding simulators and chats inside the browser with zero external installations or local dev setup required to start.
3. **Engaging Progress**: Keep learners motivated using instant gamification cues (XP, progress ring updates) and clear roadmaps.
